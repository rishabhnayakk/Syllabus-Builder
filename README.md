# Syllabus Builder

A browser-based syllabus planning tool for organizing subjects, breaking them into units and topics, and tracking study progress through a clean, focused interface.

## Overview

Syllabus Builder helps turn a large syllabus into smaller, manageable learning tasks. Its interface uses a warm, book-inspired visual theme with expandable subject sections and structured unit cards.

## Features

- **Organize subjects** — create and manage subject sections.
- **Break down the syllabus** — add units and topics under each subject.
- **Track progress** — monitor topic completion and overall study progress.
- **Persistent browser storage** — keep your work saved locally using the browser's LocalStorage.
- **Import support** — bring syllabus data into the app through its import workflow.
- **Responsive interface** — use the planner across desktop and mobile-sized screens.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Browser LocalStorage

## Run Locally

No package installation or build step is required for the current browser-based version.

1. Clone the repository:
   ```bash
   git clone https://github.com/rishabhnayakk/Syllabus-Builder.git
   ```
2. Open `builder/index.html` in your browser.

You can also serve the repository with a simple local HTTP server if you prefer.

## Data & Privacy

The current version stores planner data in the browser's LocalStorage. This means the data is associated with the browser and device where you use the app. Clearing browser site data may remove locally stored planner information, so export or back up important data if the app's import/export workflow supports your use case.
